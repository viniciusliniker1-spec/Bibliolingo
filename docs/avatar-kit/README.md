# Bibliolingo Avatar Kit v1

Objetivo: editor modular de avatar no Android, aberto ao tocar na silhueta do perfil, sem carregar assets na Home.

## Referências
Arte conceito aprovada na conversa do Bibliolingo: perfil escuro, personagem chibi, escolhas de aparência, cabelo, roupas e acessórios. A arte conceito é uma referência, não um sprite de produção.

## Entrega incremental
1. Implementar editor navegável com dados de catálogo e preview, sem exigir sprites inexistentes.
2. Persistir seleção por usuário, validar reabertura e sincronização existente.
3. Integrar avatar ao perfil.
4. Integrar o mesmo avatar ao mapa de jornadas somente após validação.
5. Produzir sprites modulares e miniaturas conforme contrato técnico.

Não alterar a Web nem main. Não gerar combinações em massa. Não afirmar que há sprites finais quando ainda não existem.
